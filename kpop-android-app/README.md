# 특징

## 1. 홈 화면

### 1-1. 최근 연습한 안무 표시

안무를 연습하면 마지막 연습 날짜와 함께 최대 4개까지 최근에 연습한 안무가 표시됩니다.

## 2. 검색 화면

### 2-1. 검색 필터링

검색 필터링이 가능하도록 했습니다.

난이도, 아티스트 성별, 템포 등을 선택할 수 있습니다. 이 세 가지를 모두 선탟하지 않아도 필터링 검색이 동작하도록 구현했습니다.

### 2-2. 검색 결과 화면 애니메이션

검색 결과 화면에서 검색된 안무 목록이 뜰 때 안무 리스트가 순서대로 나열되는 애니메이션을 적용하여 자연스럽고 재미있는 동작을 구현했습니다.

## 3. 안무 연습

### 3-1. 파트 선택 화면

안무 파트를 선택할 때 직접 연습하거나 미리 촬영된 안무 연습 영상을 업로드 할 수 있도록 했습니다.

파트 선택 진입 시 검색 결과 애니메이션과 동일한 애니메이션을 적용하여 자연스러운 전환을 구현했습니다.

### 3-2. 안무 연습 1차 화면

사용자가 안무를 연습하기 전 안무를 미리 볼 수 있도록 구현했습니다. 이 때 처음부터 다시 보기, 일시 정지, 안무 연습하기(따라하기) 버튼을 구현하고, 재생 속도를 0.5배부터 1.5배까지 가능하도록 했습니다.

또한 오른쪽 상단에 음소거 버튼과 안무 연습에 관련된 설정을 조작할 수 있는 버튼을 구현했습니다.

### 3-3. 안무 연습 2차 화면

스마트폰의 경우, 전문가 영상이 화면 전체에 띄워지고 사용자 카메라 영상은 오른쪽 하단에 작게 표시되도록 하여 작은 스마트폰 화면에서도 사용자가 자신의 모습을 보면서 전문가 영상을 볼 수 있도록 했습니다.

태블릿/모니터의 경우, 왼쪽에 전문가 영상이 나오고 오른쪽에 사용자 영상이 나오도록 구현하여 넓은 화면을 효율적으로 활용하도록 했습니다.

## 4. 프로필 화면

프로필 화면에는 통계, 업적, 설정 화면을 아래에 UI만 바뀌도록 구현했습니다. 이를 통해 사용자는 큰 화면 전환 없이 즉시 해당 메뉴들을 이용할 수 있도록 했습니다.

그리고 이러한 통계, 업적, 설정 화면이 전환됨에 따라 자연스러운 애니메이션을 적용하여 사용자가 화면 전환에 대해 인식하고 부드러운 경험을 할 수 있도록 했습니다.

그리고 상단에는 사용자의 프로필과 상세 통계를 볼 수 있는 버튼을 구현했습니다.

### 4-1. 통계 화면

사용자의 연습 시간, 연습 완료한 곡 개수, 평균 정확도가 표시되며

가장 많이 연습한 TOP 3 안무와 진행 중인 업적 목록들이 표시되도록 했습니다.

제일 아래에는 현재 획득한 뱃지를 볼 수 있도록 했습니다.

### 4-2. 업적 화면

완료된 업적, 진행 중인 업적, 진행하지 못 한 업적들이 나열되도록 했습니다.

### 4-3. 설정 화면

프로필 설정, 연습 화면 설정, 알림 설정, 개인정보 보호 및 권한, 앱 정보, 최신 데이터 동기화, 회원 탈퇴 기능을 구현했습니다.

또한 이러한 세부 설정 화면으로 넘어갈 때, 안드로이드 스마트폰의 기본 설정 화면 전환 방식을 동일하게 적용하여 기존의 안드로이드 스마트폰 사용자가 익숙한 경험을 받도록 했습니다.
