# 홈 프로모 비디오 종료 후 카드 모션 끊김 분석

## 현상
- 홈 화면에서 `home_intro.mp4` 재생이 끝난 뒤, 아래 카드 섹션이 위로 올라오는 순간 모션이 미세하게 끊겨 보입니다.
- 체감상 애니메이션 easing 문제라기보다, 비디오 종료 시점과 레이아웃 재배치가 한꺼번에 일어나면서 발생하는 hitch에 가깝습니다.

## 현재 구현 구조
- 홈 화면은 `LazyColumn` 안에 검색 영역, 프로모 비디오, 카드 섹션들이 순서대로 들어 있습니다.
- 프로모 비디오는 `AnimatedVisibility`의 `shrinkVertically + fadeOut`으로 사라집니다.
- 비디오는 Compose 순수 컴포넌트가 아니라 `AndroidView(PlayerView)` + `ExoPlayer`로 렌더링됩니다.
- 비디오 아래에는 `RecentChoreoSection`, `RegisteredChoreoSection`, `TrendingChallengeSection`이 배치되어 있고, 각 섹션은 `LazyRow` 기반 카드 목록을 포함합니다.

## 원인 추론

### 1. 비디오 높이 축소와 함께 아래 콘텐츠 전체가 재배치됨
`shrinkVertically`는 비디오 영역 높이를 실제로 줄입니다. 이때 아래 카드 섹션 전체의 위치가 프레임마다 다시 계산되므로, 레이아웃/배치 비용이 애니메이션 중첩으로 들어갑니다.

### 2. 종료 대상이 `AndroidView(PlayerView)`라 전환 비용이 더 큼
비디오 종료 시점에는 재생 종료 이벤트, Surface 정리, `ExoPlayer.release()` 흐름이 레이아웃 변화와 겹칠 수 있습니다. 순수 Compose 박스보다 `AndroidView` 제거 시 hitch가 더 두드러질 수 있습니다.

### 3. 아래 카드 섹션이 가볍지 않음
아래 카드들은 이미지 로딩(`AsyncImage`), `graphicsLayer`, `onGloballyPositioned` 좌표 계산 등을 포함합니다. 평소에는 괜찮더라도 상위 레이아웃이 크게 변하는 순간에는 함께 부담이 올라갑니다.

### 4. 비디오 종료와 레이아웃 축소가 같은 타이밍에 시작됨
현재 구조에서는 `Player.STATE_ENDED`가 발생하자마자 바로 비디오 제거 애니메이션이 시작됩니다. 사용자는 이 타이밍을 아주 민감하게 느끼기 때문에, 마지막 프레임 종료와 레이아웃 접힘이 동시에 오면 모션이 덜 자연스럽게 보일 수 있습니다.

## 해결 방향 후보

### 방법 A. 비디오 높이를 직접 줄이지 말고 아래 카드만 offset/translation으로 올리기
- 비디오 레이아웃 자체를 프레임마다 줄이지 않습니다.
- 대신 아래 카드 컨테이너를 `translationY`로 위로 올려서 시각적으로 자연스럽게 연결합니다.
- 애니메이션이 끝난 뒤에 비디오를 레이아웃에서 제거하면, 중간 프레임의 measure/layout 부담을 줄일 수 있습니다.

### 방법 B. 비디오 페이드아웃과 레이아웃 정리를 단계 분리
- 종료 직후 바로 접지 말고 먼저 `fadeOut`만 적용합니다.
- 그 다음 짧은 지연 뒤에 레이아웃을 정리하면 전환 경계가 덜 거칠게 느껴질 수 있습니다.

### 방법 C. 종료 후 짧은 완충 시간 두기
- `STATE_ENDED` 직후 80~150ms 정도 마지막 프레임을 유지한 다음 다음 모션을 시작하면 체감이 부드러워집니다.

### 방법 D. 비디오 컨테이너의 렌더링 비용 줄이기
- `Surface`의 그림자, clip, shape 비용을 단순화하면 저사양 기기에서 개선 여지가 있습니다.

### 방법 E. 카드의 위치 계산/재배치 민감도 낮추기
- `onGloballyPositioned` 같은 위치 계산을 꼭 필요한 시점에만 수행하도록 조정하면 상위 레이아웃 변경 시 부담을 줄일 수 있습니다.

## 이번 코드 적용 범위
이번 수정에서는 우선 **방법 A만 적용**합니다.

### 적용 방식
1. 비디오가 끝났을 때 `shrinkVertically`로 높이를 줄이지 않습니다.
2. 비디오 섹션과 카드 섹션을 하나의 컬럼으로 묶습니다.
3. 카드 섹션 전체에 `translationY` 애니메이션을 걸어 비디오 높이만큼 위로 이동시킵니다.
4. 동시에 비디오는 alpha만 0으로 페이드아웃합니다.
5. 애니메이션 종료 후 비디오를 레이아웃에서 제거하고, 카드 translation은 0으로 되돌립니다.
   - 이때 비디오 공간이 사라진 만큼 레이아웃 상 위치가 올라가므로, 사용자 눈에는 카드가 같은 위치에 자연스럽게 정착한 것처럼 보입니다.

## 기대 효과
- 애니메이션 중간 프레임마다 비디오 높이를 줄이지 않으므로 measure/layout 부담이 감소합니다.
- 시각적으로는 카드가 위로 올라오는 느낌을 유지하면서, 레이아웃 기반 hitch를 완화할 수 있습니다.
- 추후에도 끊김이 남는다면, 방법 B/C를 이어서 적용하는 것이 다음 우선순위입니다.
