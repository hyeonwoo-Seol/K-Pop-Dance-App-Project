# K-Pop Dance App 애니메이션/상호작용 추천안

작성 목적: 현재 Compose UI의 각 화면을 기준으로, **사용자가 체감하기 쉬운 동적 UX 개선 포인트**를 우선순위로 정리.

## 1) 화면별 분석 요약

### Home
- 특징: 가로 카드 리스트(`최근 연습한 안무`, `등록된 안무`, `인기 급상승`)가 반복되고, 카드 클릭이 핵심 액션.
- 현재 상태: 카드 진입/탭 피드백이 정적이며, 데이터 로딩 상태를 시각적으로 느끼기 어렵다.
- 추천:
  1. **카드 등장 Stagger 애니메이션** (LazyRow 아이템 순차 페이드+살짝 위로 이동)
  2. **카드 프레스 인터랙션** (scale 0.97 + 그림자 감소)
  3. **이미지 로딩 Skeleton/셔머** (커버 이미지 로딩 시)

### Search
- 특징: 필터 칩 선택이 핵심, 검색 버튼으로 결과 화면 이동.
- 현재 상태: 칩 선택 변화는 색상만 바뀌고 상태 변화 체감이 작음.
- 추천:
  1. **필터칩 선택 마이크로 애니메이션** (배경색 트윈 + 1.0→1.03 스케일)
  2. **검색 버튼 탭 피드백 강화** (ripple + pressed elevation)
  3. **필터 변경 시 상단에 “활성 필터 배지” 칩 정렬 애니메이션**

### Search Results
- 특징: 결과 리스트와 Empty 상태가 분기.
- 현재 상태: 상태 전환이 즉시 바뀌어 UX가 다소 건조.
- 추천:
  1. **Empty ↔ Results Crossfade**
  2. **결과 카드 진입 애니메이션** (첫 렌더링 시 순차 슬라이드)
  3. **리스트 아이템 클릭 시 Shared-like 전환** (SongDetail로 썸네일 확장 느낌)

### Song Detail / Song Part Select
- 특징: 학습 진입 전 의사결정(파트 선택, 연습/업로드).
- 현재 상태: 기능은 충분하나 CTA 강조와 맥락 전달이 약함.
- 추천:
  1. **하단 CTA 버튼 펄스(저강도)**: 첫 진입 2~3초만
  2. **파트 카드 펼침/접힘 인터랙션**: 파트별 길이/난이도/추천 포인트 노출
  3. **업로드 진행 단계 모달**: 업로드→분석대기 전환 시 단계 모션 통일

### Practice (모바일)
- 특징: 이미 상/하단 컨트롤 `AnimatedVisibility` 적용됨.
- 현재 상태: 핵심 컨트롤은 잘 되어 있으나 학습 보조 인터랙션 추가 여지 큼.
- 추천:
  1. **속도 변경 시 순간 토스트 대신 HUD 배지 애니메이션** (`1.25x` 배지가 800ms 표시)
  2. **반복 구간 A-B 설정 인터랙션** (슬라이더에 핸들 2개 + 하이라이트 영역)
  3. **비트 맞춤 진동/시각 피드백** (옵션 ON 시 박자선 점멸)

### Analysis Loading
- 특징: 이미 단계별 진행률/팁 로테이션 있음.
- 현재 상태: 기본은 좋지만 “실제 진행” 체감이 약함(시뮬레이션 느낌).
- 추천:
  1. **실제 백엔드 단계 이벤트 연동** (업로드 %, 큐 대기, 모델 추론 단계)
  2. **단계 전환 모션 통일** (텍스트 slide+fade)
  3. **예상 남은 시간 범위 표시** (예: 약 20~40초)

### Practice Result
- 특징: 점수/등급/오버레이 보기 CTA 존재.
- 현재 상태: 결과 노출이 즉시 완료형이라 성취감 연출이 약함.
- 추천:
  1. **점수 카운트업 애니메이션** (0→최종점수 1.2초)
  2. **레이더/바 차트 드로잉 애니메이션**
  3. **오류 관절 하이라이트 순회 재생** (주요 개선 포인트 3개 자동 포커스)

### Profile
- 특징: 통계/업적/설정 탭 구조와 진행바 데이터가 강점.
- 현재 상태: 탭 전환/업적 달성 피드백이 정적.
- 추천:
  1. **탭 전환 애니메이션** (indicator slide + content fadeThrough)
  2. **업적 달성 순간 confetti-lite/Lottie** (과하지 않게 1초 내)
  3. **경험치 바 증가 모션** (동기화 후 delta만큼 애니메이션)

## 2) 우선순위 제안 (ROI 기준)

### P0 (바로 체감, 개발 난이도 중간)
1. Practice Result 점수 카운트업 + 차트 드로잉
2. Search Results 상태 전환(Crossfade) + 카드 진입
3. Home 카드 프레스/등장 애니메이션

### P1 (제품 완성도 상승)
1. Profile 탭 전환 + 경험치 증가 모션
2. Song Part Select 카드 확장형 인터랙션
3. Analysis Loading 실제 이벤트 연동

### P2 (차별화 요소)
1. Practice의 A-B 루프 인터랙션
2. Shared transition 기반 상세 진입
3. 박자 피드백(시각/햅틱)

## 3) 디자인/개발 가이드라인

- **원칙 1: 150~350ms 중심**
  - 마이크로 인터랙션은 120~220ms, 화면 전환은 220~350ms 권장.
- **원칙 2: 의미 있는 움직임만**
  - 사용자의 의사결정(선택/확인/완료)을 강화하는 모션에 집중.
- **원칙 3: 성능 우선**
  - 저사양 기기에서 60fps 유지가 어려운 효과(과도한 blur/복합 transform)는 제한.
- **원칙 4: 접근성 고려**
  - 시스템 애니메이션 축소 설정 시 모션 강도 자동 축소.

## 4) 구현 순서 제안 (2주 스프린트 예시)

- 1주차
  - Search Results 상태 전환 + Home 카드 인터랙션
  - Practice Result 점수/차트 애니메이션
- 2주차
  - Profile 탭/XP 모션
  - Song Part Select 확장 카드
  - Analysis Loading 실시간 이벤트 훅 정리

## 5) 기대 효과

- 첫 사용자의 “앱이 살아있다” 인상 강화
- 결과 화면의 성취감 증가로 재연습 유도
- 검색/선택 플로우의 결정 피로 감소
- 프로필/업적 체류 시간 증가
